# Публичный MCP и локальный запуск

В русскоязычном форке публичный MCP-сервис не является поддерживаемым способом запуска. Обновление исходников не разворачивает сервис и не создаёт учётные записи. Upstream v3.1.0 также завершает поддержку своего публичного endpoint.

Для этого форка используйте [локальную инструкцию MCP](LOCAL_MCP.md) или выборочную [установку навыков в Codex](CODEX.md). Этот файл сохранён как переход со ссылок в документах upstream; он не возвращает Vercel, публичную регистрацию или облачную авторизацию.
